# Ebooks de Filipe Ivo Pereira

Repositório organizado dos eBooks e capas preparados para publicação no Amazon KDP.

## Estrutura

- `books/<slug>/ebook.epub` — arquivo EPUB canônico de cada livro.
- `books/<slug>/cover.jpg` — capa correspondente ao EPUB, em versão pronta para o KDP.
- `CATALOGO.md` — lista navegável de todos os livros e links para os arquivos.
- `catalog.json` — catálogo em formato estruturado para o site e outras automações.
- `assets/covers-original/` — capas originais fornecidas para o KDP, preservadas sem alteração.
- `archive/output-variants/` — versões anteriores e variantes geradas durante a preparação; os arquivos canônicos ficam em `books/`.

## Livros incluídos

São 21 livros com EPUB e capa correspondente. As versões escolhidas são as mais recentes/preparadas para o KDP; variantes anteriores foram mantidas no arquivo para não perder histórico.

## Uso

Abra `CATALOGO.md` para navegar pelos livros ou use `catalog.json` para integração automática. Os caminhos são relativos ao repositório e os arquivos podem ser baixados diretamente pelo GitHub.
